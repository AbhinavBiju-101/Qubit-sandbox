MODULE 3 · THE MATH UNDERNEATH

Measurement never returns anything but an eigenvalue.

Every Stern-Gerlach "up" or "down," every single-qubit measurement in this app, has secretly been reporting one specific number: an eigenvalue of whatever you measured. Five steps, including how to actually find eigenvalues from scratch instead of just checking guesses.

1

M|v⟩ = λ|v⟩

A vector |v⟩ is an eigenvector of a matrix M if applying M doesn't rotate it at all — only rescales it by some number λ, its eigenvalue: M|v⟩ = λ|v⟩. For the Z operator, |0⟩ and |1⟩ are eigenvectors with eigenvalues +1 and −1. For X, it's |+⟩ and |−⟩ with the same two eigenvalues.

The measurement postulate, stated precisely: measuring observable M can only ever return one of its eigenvalues, and the state collapses to the matching eigenvector. Every "up/down," "+1/−1" result you've seen in this app has literally been one of these two numbers.

This is also why Hermitian matrices matter for observables (Operator Types, previous lesson): a Hermitian matrix is mathematically guaranteed to have only real eigenvalues — you'll never measure an observable and get an imaginary number back.
2

Where +1 and −1 for X actually come from

Step 1 handed you X's eigenvalues and eigenvectors ready-made. Worth deriving them once instead of just trusting the claim — the general method is called the characteristic equation, and it works for any matrix, not just the ones this app happens to use. Rearrange M|v⟩ = λ|v⟩ as (M − λI)|v⟩ = 0. A nonzero vector can only solve this if M − λI has no inverse, which happens exactly when its determinant is zero: det(M − λI) = 0.

Apply this to X = [[0,1],[1,0]]:

X − λI = [[−λ, 1], [1, −λ]]

det(X − λI) = (−λ)(−λ) − (1)(1) = λ² − 1 = 0

λ² = 1   →   λ = +1 or λ = −1

That confirms the eigenvalues without ever guessing a vector. Now find the actual eigenvector for λ=1 by plugging back into (X−I)|v⟩=0: [[−1,1],[1,−1]] times (v₀,v₁) equals zero means −v₀+v₁=0, i.e. v₀=v₁ — any vector with equal entries works, and normalizing gives exactly (1/√2, 1/√2) = |+⟩. The same process with λ=−1 forces v₀=−v₁, giving |−⟩. Nothing in Step 1 was asserted without a reason — this is where both numbers, and both vectors, actually come from.

Bonus: the sequential Stern-Gerlach experiment, in this language

Measurement & Stern-Gerlach's Z→X→Z cascade makes perfect sense now: the atom starts as an eigenvector of Z. Measuring X forces a collapse onto an eigenvector of X instead — which is not an eigenvector of Z. So the following Z-measurement is back to a genuine 50/50, because the state has left Z's eigenbasis entirely.

5

Degenerate eigenvalues: more than one eigenvector, same number

Z and X each have two different eigenvalues (+1 and −1), each with exactly one eigenvector (up to a phase). Some operators aren't so clean: the identity matrix I sends every vector to itself unchanged — I|v⟩ = 1·|v⟩ for literally any |v⟩. Every vector in the whole space is an eigenvector of I, all sharing the single eigenvalue 1. That's called a degenerate eigenvalue — the same word Particle in a Box and The 3D Box used for energy levels shared by multiple distinct states, because it's the identical idea: one number, more than one eigenvector behind it.

Degeneracy matters practically because a measurement that returns a degenerate eigenvalue tells you less than a non-degenerate one — you learn which number you got, but not which of the several eigenvectors sharing it the state collapsed to.
