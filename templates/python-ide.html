The code behind the sandbox

These are real qiskit snippets — not illustrations. Hit "Run" and it calls the same /api/compare-shots Flask endpoint the Single Qubit lesson's Step 5 uses, which runs your circuit on real qiskit-aer server-side and returns actual counts.

Code editor

A real code editor, not just fixed buttons — but running arbitrary Python server-side is a genuine security problem, so this runs a restricted subset: build a QuantumCircuit named qc, call gate methods on it (h x y z ry rx rz cx measure measure_all barrier), do simple arithmetic — no import, no loops, no function/class definitions, no other function calls. Every "Open in editor" button below loads real, runnable code here. Max 3 qubits, 60 operations, 3 second timeout.

YOUR CIRCUIT
Not a general Python sandbox, on purpose. The restriction above isn't a placeholder for "coming later" — running someone's arbitrary code on a server is a real security problem (filesystem/network access, resource exhaustion), and this project takes the position that a small, genuinely safe subset beats a big unsafe one. See futureplans.md #12 and the comment above /api/run-code in app.py for the full reasoning.
HADAMARD — SUPERPOSITION
from qiskit import QuantumCircuit from qiskit_aer import AerSimulator qc = QuantumCircuit(1, 1) qc.h(0) # put qubit 0 into superposition qc.measure(0, 0) result = AerSimulator().run(qc, shots=1000).result() print(result.get_counts())

.h() — Qiskit docs: QuantumCircuit.h()

PAULI-X — BIT FLIP
from qiskit import QuantumCircuit from qiskit_aer import AerSimulator qc = QuantumCircuit(1, 1) qc.x(0) # flip |0⟩ -> |1⟩, deterministic qc.measure(0, 0) result = AerSimulator().run(qc, shots=1000).result() print(result.get_counts())

.x() — Qiskit docs: QuantumCircuit.x()

RY(θ) — TUNABLE ROTATION
import math from qiskit import QuantumCircuit from qiskit_aer import AerSimulator theta_deg = 60 qc = QuantumCircuit(1, 1) qc.ry(math.radians(theta_deg), 0) # P(0) = cos²(θ/2) qc.measure(0, 0) result = AerSimulator().run(qc, shots=1000).result() print(result.get_counts())

Two-qubit circuits

Same idea, extended to two qubits — hits a second endpoint (/api/compare-shots-2q) that builds a real 2-qubit QuantumCircuit and returns all four outcome counts.

PREPARE |11⟩
from qiskit import QuantumCircuit from qiskit_aer import AerSimulator qc = QuantumCircuit(2, 2) qc.x(0) # flip qubit 1 qc.x(1) # flip qubit 2 qc.measure([0, 1], [0, 1]) result = AerSimulator().run(qc, shots=1000).result() print(result.get_counts())

.x() — Qiskit docs: QuantumCircuit.x()

BELL STATE — H(q1) → CNOT(q1→q2)
from qiskit import QuantumCircuit from qiskit_aer import AerSimulator qc = QuantumCircuit(2, 2) qc.h(0) # superposition on qubit 1 qc.cx(0, 1) # entangle: flip qubit 2 iff qubit 1 is |1⟩ qc.measure([0, 1], [0, 1]) result = AerSimulator().run(qc, shots=1000).result() print(result.get_counts()) # expect ~50/50 split between '00' and '11' only
