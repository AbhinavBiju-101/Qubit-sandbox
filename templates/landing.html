WHY THIS EXISTS

    
Most explanations stop at the analogy

    
"A qubit is like a coin that's both heads and tails" is where most explainers end. Qubit Sandbox is the next step down — the actual amplitudes, the actual matrices, the actual measurement statistics — so the analogy stops being necessary.

    PYTHON IDE
  

  
A real code editor, not just preset buttons

  
Write Qiskit by hand — loops, branching, print(), input() — and run it against a genuine qiskit-aer simulator. It's a restricted grammar, not a full Python sandbox — no imports, no filesystem or network access — but everything a real circuit needs is there.


  

    

      

      
Loops & branching

      
for/while loops and if/elif/else — build a GHZ state across N qubits in three lines instead of typing every gate.

    

    

      

      
Console & stdin

      
A real output console keeps a history of every run instead of overwriting the last one, and input() reads from a stdin box you fill in beforehand.

    

    

      

      
Syntax highlighting

      
A proper code editor with line numbers, colored syntax, and a working Tab key — not a plain textarea pretending to be one.
